# REFRIPRÓ PARTS - Controle de Estoque

MVP desenvolvido para auxiliar no controle de estoque da REFRIPRÓ PARTS, um pequeno comércio de peças de refrigeração.

## Objetivo

Facilitar o cadastro e o controle das peças disponíveis no estoque de forma simples e organizada.

## Funcionalidades

- Cadastro de peças
- Consulta das peças cadastradas
- Controle de quantidade
- Edição de peças
- Exclusão de peças

## Tecnologias utilizadas

- Python
- Flask
- HTML
- Git e GitHub

## Testes

O projeto possui testes automatizados para verificar funcionalidades básicas do sistema, como acesso à página inicial, cadastro e exclusão de peças.

## Como executar

1. Instale o Python.
2. Instale o Flask com `pip install flask`.
3. Execute o arquivo com `python app.py`.
4. Acesse `http://127.0.0.1:5000` no navegador.

## Projeto acadêmico

Projeto desenvolvido como MVP para a disciplina de Projeto de Software.



## Revisão técnica

Durante a revisão do MVP, foi verificado que as funcionalidades principais de cadastro, consulta, edição e exclusão de peças estão organizadas de forma simples e adequada ao objetivo do sistema.

Também foram incluídos testes automatizados para auxiliar na verificação das funcionalidades e na manutenção da qualidade do código.
